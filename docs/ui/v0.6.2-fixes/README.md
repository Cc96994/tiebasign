# v0.6.2 修复证据（用户反馈：并发确认 / 查封分类 / 失效贴吧 / 暂停）

> 真实页面截图（App 自己渲染），虚构账号/错误码，不含真实 BDUSS。

## 场景与参数

- **Before** = 0.6.1（提交 `b1dfb47`）；**After** = 0.6.2。
- 主题浅色，视口 `500 × 1100`（签到页）/ `500 × 900`（设置页），
  `devicePixelRatio = 2`。

### 1. 补签并发跟随档位

- 0.6.2 截图里运行中的步骤直接写「逐吧补签 3/12（并发 4）」；并发来自
  设置里的速度档位，测试另外断言「极速档 = 8 并发、保守档 = 2 并发」。
- 一键签到顺序本来就是：先 msign（百度一键签到），失败就跳过，再逐吧补签。

### 2. 吧已查封的错误分类

12 个待签吧，其中一个返回 `340006`。

- Before（0.6.1）：`340006` 被当成限流，记 1 个失败并触发熔断降档提示。
- After（0.6.2）：识别为「吧已查封」，跳过且不计失败，也不触发熔断/硬停；
  页面显示「已跳过 1 个吧（已查封/关闭，不计失败）」。

### 3. 失效贴吧

- 设置首页新增「失效贴吧」入口。
- 页面可添加/删除吧名；标记后签到和点赞会直接过滤掉这些吧（截图是
  已标记「摄影吧」的状态）。
- 0.6.1 没有这一页，因此设置页用 Before/After 入口对比，页面本身只有 After。

### 4. 手动暂停

- 运行中的签到和随机点赞各有一个「暂停 / 继续」按钮；Before 没有。
- 暂停只停新的补签/取帖/点赞请求，进行中的请求会自然完成；状态和按钮
  在暂停后显示「继续」。
