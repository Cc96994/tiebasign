# v0.6.1 修复证据（用户反馈：msign 跳过 + 自动重试）

> 真实页面截图（App 自己渲染），虚构账号/错误码，不含真实 BDUSS。

## 场景与参数

- **Before** = 0.6.0（提交 `894ba37`）；**After** = 0.6.1。
- 主题浅色，视口 `500 × 1100`（签到页）/ `500 × 1250`（自动签到设置），
  `devicePixelRatio = 2`。
- msign 场景：12 个待签吧，`msign` 返回 `340011`。
  - Before：整批停止，页面显示「网页一键签到被限制，已停止逐吧补签」。
  - After：msign 只跳过，继续逐吧补签 12/12，成功 12、失败 0；
    「提醒」卡片显示真实原因/错误码（操作太快、340011）。
- 自动签到设置：Before 没有重试输入；After 增加「失败后自动重试（分钟，1-120）」，
  默认 5，提示最多重试 3 次、重试期间不通知、成功或次数用完才提醒。

## 说明

- 逐吧 `sign_forum` 仍然单次、不重试；这里重试的是**自动签到整体**：
  失败后按 `retry_minutes` 再跑，最多 3 次；重试期间不弹通知/不亮红点，
  成功或次数用完才提醒。逐吧硬停/熔断（验证码、登录问题、保守档仍限流）保留。
- 0.6.1 是本地测试版本：0.6.0 的样本已安装过，p4a 用版本号缓存 Python 代码，
  同一个版本号重编在真机上会继续跑旧代码，所以修好后把版本提到 0.6.1。
