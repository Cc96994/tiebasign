## 0.6.3 其它修复（无界面变化，测试覆盖）

1. **暂停更彻底**：暂停检查加到了 msign / 取列表 / 翻页 / 点赞重试之前；
   暂停后不再发新的签到/取帖/点赞请求，进行中的请求自然完成。
2. **随机点赞自动跳过失效吧**：点赞遇到 `340006` / `340001`（吧已查封）
   时自动写入「失效贴吧」列表，后续运行直接过滤，不再每次撞同一个吧。
3. **点赞提速不再撞限流**：原因是高并发/高阶档位同时打出大量请求，且令牌
   桶按并发数给突发额度。修复：点赞令牌桶 `burst=1`、全局速率硬上限
   12 次/秒；撞到 `3280004` 后当天学到的降速值会落盘，当天后续运行直接
   从低速开始（隔天重新按档位试）。
