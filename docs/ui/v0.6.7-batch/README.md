## 0.6.7 行为

- 去掉 0.6.6 的「每个点赞请求固定间隔 5 秒」。
- 按档位并发数分批：一批最多同时发 3 / 5 / 8 / 12 个点赞；这一批全部
  结束后等「分批间隔」秒再点下一批。
- 「随机点赞设置 → 分批间隔」默认 10 秒，可改 1–120；下次开始点赞时生效。
- 当天已经点过的吧先在本地过滤，不占批次等待；批内没有任何点赞请求
  （全是本地跳过/取帖失败）时不会空等间隔。
- 令牌桶的突发额度改为一整批的并发数（否则批内仍会被逐请求串行化）；
  D-36 的限流自动暂停、AIMD 降速和每 10 个赞休息继续保留。
