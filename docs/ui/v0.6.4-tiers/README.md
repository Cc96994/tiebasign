## 限流处理（无界面变化，代码/测试覆盖）

- 原因：高并发档位同时打出大量请求 + 令牌桶按并发数给突发额度；撞了
  `3280004` 后短冷却就重试，容易连环撞。
- 0.6.4：
  - 四档各自的目标速率：4 / 7 / 10 / 12 次/秒；
  - 令牌桶 `burst=1`，不再开跑瞬间打一批；
  - AIMD 自适应：没学过从 6 次/秒起步，整轮干净就 +1，撞限流就减半并把
    学到的速率落盘，后续运行沿用；
  - 撞限流冷却拉长到 20 / 45 秒，减少连环撞。
- 前三档的并发按用户指定 3 / 5 / 8，第四档 12；颜色按要求前两档绿色、
  第三档黄色、第四档红色。
