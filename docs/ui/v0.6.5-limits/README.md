## 0.6.5 行为

- 点赞返回 `3280004` 时：
  1. 先尝试从百度文案里解析「X 秒 / 分钟 / 小时」作为解除时间（方向 1）；
  2. 读不到就用「被限流后自动暂停」里的分钟数（默认 5，可改 1–60，方向 2）；
  3. 自动暂停期间不再发新的点赞请求，界面显示原因与等待时间；
  4. 时间到自动继续；重试仍然被限流才结束本轮（不把后面的吧记成失败，
     也不触发硬停），可稍后再点开始。
- 速度档位在启动点赞时读取一次，状态里显示档名/并发；测试断言四档（并发
  12）会传到 `like_concurrency` 并用于信号量。
- 「失效贴吧」入口/页面改名为「标记失效贴吧」，数据和过滤逻辑不变。
