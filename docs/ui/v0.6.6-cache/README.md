## 0.6.6 行为

- 随机点赞设置新增：
  - **帖子缓存**：提前缓存（开关，默认开）；每个吧缓存 7 个候选帖子，
    用完自动补一批；已点赞/无效的 tid 会清掉、不再重复选；「立即缓存」
    可手动为全部账号预缓存。
  - **点赞休息**：每 10 个赞休息，默认 2 分钟，可改 0–60；休息期间不再发
    新的点赞请求。
  - 点赞请求固定间隔 5 秒，界面不显示、不可自定义。
- 点赞一二档颜色改为蓝色；三档黄、四档红。
- 签到速度档位从独立设置页移入自动签到设置；设置首页不再有入口。
- 「失效贴吧」已在 0.6.5 改名为「标记失效贴吧」。
